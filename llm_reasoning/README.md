# LLM Reasoning (Experimental Extension)

This directory is reserved for experiments combining Large Language Models with inverse problem regularization (e.g., prompt templates for automated hyperparameter tuning, discrepancy threshold reasoning, and convergence analysis).

### Subdirectories:
- `input_jsons/`: JSON metadata describing inverse problem parameters.
- `llm_templates/`: Structured prompt templates for parameter reasoning.
- `results/`: LLM evaluation and parameter recommendation logs.
